# zornyX3D Game Engine

zornyX3D is a lightweight, command-driven 3D game engine powered by Python and Ursina. Conceptually established in 2019, the project focuses on pure code execution, fast prototyping, and minimal setup without using complex visual editors.

### Features
* 100% code-driven 3D game engine with no GUI editor overhead.
* Simple procedural commands to create, scale, rotate, and move 3D entities.
* Lightweight structure designed for retro aesthetics and rapid game development.
* Easy to integrate into standard Python workflows.

### Installation
1. Clone the repository to your system.
2. Ensure Python 3.8 or higher is installed.
3. Install the required dependency using pip install ursina.
